# Security Policy

## Reporting Vulnerabilities
If you discover a security vulnerability in Quantum Codex Crypt, please report it privately. Do not disclose publicly until fixed.

- **Email**: iamrexeditsofficial@gmail.com
- **Details**: Include reproduction steps, impact, and suggested fix.

## Best Practices
- Use the latest dependencies.
- Generate keys securely.
- Follow OSS security guidelines (e.g., from OpenSSF).

We, Rex and the Codex Team, aim to respond within 48 hours and release patches promptly.
