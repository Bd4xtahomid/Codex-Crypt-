# Contributing to Quantum Codex Crypt

Thank you for your interest in contributing! This is a non-profit, open-source project created by Rex and the Codex Team, where anyone can edit, improve, and make it better. We encourage contributions from the community.

## How to Contribute
1. **Fork the Repository**: Create your own fork on GitHub.
2. **Clone Your Fork**: `git clone https://github.com/yourusername/quantum-codex-crypt.git`
3. **Create a Branch**: `git checkout -b feature/your-feature`
4. **Make Changes**: Add features, fix bugs, update docs.
5. **Commit Changes**: `git commit -m "Add your message"`
6. **Push to Fork**: `git push origin feature/your-feature`
7. **Open a Pull Request**: Submit a PR with a clear description.

## Guidelines
- **Code Style**: Follow PEP 8.
- **Tests**: Add unit tests for new features.
- **Security**: Report vulnerabilities privately via email (iamrexeditsofficial@gmail.com) or SECURITY.md.
- **Docs**: Update README.md or other docs with changes.
- **Best Practices**: Ensure clear, repeatable code; no secrets; use PoLP.

## Security Reporting
See SECURITY.md for reporting vulnerabilities.

We appreciate all contributions!
